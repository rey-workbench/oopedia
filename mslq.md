# Instrumen MSLQ Terpilih (15 Butir) - OOPedia

Daftar 15 butir instrumen MSLQ (Motivated Strategies for Learning Questionnaire) yang direkomendasikan untuk *pre-test* dan *post-test* pada platform OOPedia.

## I. Motivasi (Motivation Scales)

### Self-Efficacy for Learning & Performance
1. **(Butir 6)** Saya yakin saya dapat memahami konsep yang paling sulit yang diajarkan oleh dosen di mata kuliah ini.
2. **(Butir 12)** Saya yakin saya dapat mempelajari materi dasar yang diajarkan di mata kuliah ini.
3. **(Butir 15)** Saya yakin saya dapat memahami materi yang paling rumit yang disampaikan oleh dosen di mata kuliah ini.
4. **(Butir 29)** Saya yakin saya dapat menguasai keahlian yang diajarkan di kelas ini.
5. **(Butir 31)** Saya yakin saya dapat mengerjakan tes di mata kuliah ini dengan baik.

### Intrinsic Goal Orientation
6. **(Butir 16)** Di kelas seperti ini, saya lebih suka materi yang membangkitkan rasa ingin tahu saya meskipun sulit untuk dipelajari.
7. **(Butir 22)** Hal yang paling memuaskan bagi saya di kelas ini adalah mencoba untuk memahami materi sedalam mungkin.

### Task Value
8. **(Butir 17)** Saya sangat menyukai materi kuliah di mata kuliah ini.
9. **(Butir 23)** Saya pikir materi kuliah di kelas ini berguna bagi saya untuk dipelajari.
10. **(Butir 27)** Memahami materi kuliah ini sangat penting bagi saya.

## II. Strategi Belajar (Learning Strategies Scales)

### Metacognitive Self-Regulation
11. **(Butir 55)** Saya mencoba menentukan materi mana yang belum saya pahami dengan baik.
12. **(Butir 61)** Bila saya sedang belajar, saya menetapkan tujuan untuk diri saya sendiri guna mengarahkan kegiatan belajar saya.
13. **(Butir 75)** Bila saya belajar, saya mencoba memutuskan konsep mana yang paling tidak saya pahami dengan baik.

### Critical Thinking
14. **(Butir 38)** Seringkali saya bertanya pada diri saya sendiri tentang hal-hal yang saya baca di kelas ini untuk menentukan apakah hal-hal tersebut meyakinkan.
15. **(Butir 67)** Bila saya sedang belajar, saya mencoba memikirkan alternatif cara untuk memecahkan sebuah masalah.

---
**Catatan Penting:** 
Instrumen ini menggunakan skala Likert 1-7 (1: Sangat Tidak Setuju, 7: Sangat Setuju). Untuk analisis data *pre-test* dan *post-test*, disarankan menggunakan uji statistik *Paired T-Test* atau *Wilcoxon Signed Rank Test* untuk melihat efektivitas platform OOPedia terhadap perubahan motivasi dan strategi belajar mahasiswa.
