# Tech Stack

## Backend
- **Framework:** Laravel 12.x
- **Language:** PHP 8.4
- **Database:** MySQL
- **Auth:** Laravel Sanctum v4

## Frontend
- **Framework:** Svelte 5
- **Routing/Bridge:** Inertia.js v3
- **Styling:** Tailwind CSS v4
- **Build Tool:** Vite 7
- **Language:** TypeScript/JavaScript

## Key Patterns
- Forward-chaining rule engine for adaptive learning
- Inertia.js Server-Side Rendering (SSR) capable
- Single Page Application (SPA) architecture
