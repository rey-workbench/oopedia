# Integrations & Key Dependencies

## Internal Systems

- **Laravel Sanctum:** API token authentication and SPA authentication.
- **Inertia.js Svelte adapter:** Seamlessly connects Laravel routing and controllers to Svelte 5 frontend components.

## Survey & Testing Tools

- **MSLQ (Motivated Strategies for Learning Questionnaire):** Integrated learning strategy assessment.
- **SUS (System Usability Scale):** Built-in usability testing surveys.
- **UEQ (User Experience Questionnaire):** 26-item built-in survey for user experience evaluation.

## External Libraries

- **Tailwind CSS v4 & PostCSS:** Utility-first CSS framework integration.
- **Svelte Motion / Lucide-Svelte:** Frontend animation and icon integrations.
